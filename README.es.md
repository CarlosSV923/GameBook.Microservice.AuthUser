# GameBook.Microservice.AuthUser

[Leer este README en inglés](README.md)

`GameBook.Microservice.AuthUser` será el servicio de cuentas y autenticación de GameBook, un proyecto de portfolio para explorar videojuegos y guardar favoritos personales.

## Responsabilidad

El servicio será propietario de las cuentas de usuario, el inicio de sesión, la emisión y validación de JWT, la revocación de sesiones y el cambio de contraseña. Está previsto con NestJS, Prisma y PostgreSQL, mediante una estructura orientada a DDD y una interfaz OpenAPI/Swagger.

## Estado del repositorio

Este repositorio contiene la base inicial del proyecto. La implementación de la aplicación, la infraestructura y el despliegue están programados intencionadamente como tareas SDD posteriores.
