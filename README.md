# GameBook.Microservice.AuthUser

[Read this README in Spanish](README.es.md)

`GameBook.Microservice.AuthUser` is the planned account and authentication service for GameBook, a portfolio project for exploring video games and saving personal favorites.

## Responsibility

The service will own user accounts, login, JWT issuance and validation, session revocation, and password changes. It is planned with NestJS, Prisma, and PostgreSQL, using a DDD-oriented structure and an OpenAPI/Swagger interface.

## Repository status

This repository contains the initial project foundation. Application implementation, infrastructure, and deployment are intentionally scheduled as later SDD tasks.
